Database Engine & Architecture

Active Engine: MySQL / SQLite Hybrid

The FastAPI backend connects through SQLAlchemy 2.0 ORM. When MySQL is available on port 3306, it attaches directly; otherwise, it seamlessly persists data to high-performance local SQLite storage.

FastAPI REST Endpoints:

GET /api/analytics/overview   (KPI Analytics & Trends)
GET /api/feedback              (Paginated Feedback Feed)
POST /api/feedback             (Analyze & Insert Feedback)
GET /api/analytics/issues      (Extracted Priority Issues)
